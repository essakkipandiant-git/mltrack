# MLTrack

A modern, responsive web application for managing courses, tracking lectures, assignments, and integrated media playback (including Telegram media indexing and video streaming).

## Features

- **Course Scanner & Organization**: Index lecture archives and video contents structured by days and topics.
- **Advanced Player**: In-browser video player with custom controls, playback speed, subtitle support, and resume capability.
- **Assignment Tracker**: Track progress on course assignments and self-study materials.
- **Telegram Integration**: Browse and stream media from connected Telegram channels and chats with seeking support.

## Getting Started

### Prerequisites

- Node.js 18+ or 20+
- pnpm (recommended) or npm

### Installation

```bash
pnpm install
```

### Development Server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deploying to Vercel

1. Push your repository to GitHub.
2. Import the repository in [Vercel](https://vercel.com/new).
3. Vercel will automatically detect Next.js and use `vercel.json` and `pnpm-lock.yaml`.
4. Deploy!
